# Scorpion SC-8 八足仿生机械蝎子 · 机械设计方案

版本：R1（2026-11-03） · 依据：`sc-scorpin.md`（技术设计规范）、`pic/` 三视图与机械原理图、官方参考影像
数值来源：`sims/scorpion-shared/kin.js`。本文所有尺寸、质量、重心、支撑裕度、关节扭矩与丝杠参数都由该文件计算，
动画、控制台读数与本文使用同一组函数，不存在两套数字。标注“估算”的数值不在 kin.js 中，是按文中写明的假设做的工程估计，
需在详细设计阶段复核。

坐标系（全文统一）：单位 m / mm，x 向前（指向双钳），y 向上，z 向机器人左侧；原点在髋线正下方的地面上。

本次重建对原概念参数做了以下修改，均为满足包络、造型或强度：

1. 钳臂、前臂、钳掌、钳指长度由 270/270/200/250 mm 改为 250/250/180/225 mm。原尺寸下钳尖全伸展时到 x = 1.42 m，整机长度为 2289 mm，超出 2180 mm。
2. 尾根 J1 位置改为 (−500, 490) mm，静止姿态 J1/J2 改为 125°/−20°，并采用更圆、更高的尾弧（与三视图侧视一致）。原姿态尾弧最后端到 x = −0.87 m，同样超出长度。
3. 腿部改为大腿 400 mm、小腿 700 mm（原 360/460 mm），站立时膝关节高 685–700 mm，与三视图正视中高拱的膝部一致。足端中性半径 `FOOT_R` 改为 478 mm，使外侧足垫边缘不超出 1530 mm 宽度。
4. 尾刺载荷保留原理图的 1200 N，并明确为**峰值冲击力**（`STINGER.impact` = `SPEC.strike` = 1200 N）。该值由冲刺速度、尾部等效质量和尖端柔性缓冲行程计算得到，见 B.5。另外给出**静态保持/按压力** 100 N（`STINGER.force`）：冲刺到位后持续压住目标时，J2 的力臂为 583 mm，扣除自重弯矩后只能承担 100 N。两个数值适用于不同工况，互不矛盾。

### A.3 主要受力路径

1. **竖向载荷（自重 4120 N）**：各部件 → 弹性隔离座 → 承载骨架 → 左右侧承载梁 → 8 个髋座法兰 → 髋俯仰驱动器（交叉/角接触轴承承受径向力与倾覆力矩，减速器只承受驱动扭矩）→ 大腿箱型连杆 → 膝驱动器 → 小腿连杆 → 被动踝 → 足垫 → 地面。
   kin.js 按最小二乘分配着地足的竖向力，满足 ΣF = W、Σ(F·x) = W·x_cog、Σ(F·z) = W·z_cog。行走中单足竖向力最大 1304 N；L1 抬起时 7 足分担，单足 342–809 N。
2. **纵向弯矩**：前端双钳（34 kg，力臂约 0.7 m）与尾部（58 kg，力臂约 0.5 m）在躯干两端形成弯矩，由中央纵向承载梁承担；四对腿的支反力沿梁分布，梁中段弯矩最大。
3. **扭转**：三足/四足交替支撑时，对角两侧受力不等，躯干受扭。横向加强梁与上下面板构成闭口箱型截面，承担这部分扭矩。
4. **尾部弯矩**：尾部各节自重与尾刺接触力 → 各尾节输出法兰 → 尾根 J1（2-DOF，静弯矩峰值 91 N·m，冲击峰值 86 N·m）→ 尾根连接座（220 × 240 mm 截面）→ 后端承载框架 → 中央纵向梁。尾根座用两排螺栓沿纵向分布，把弯矩转换成一对拉压力。
5. **夹持反力**：6.2 kN 夹持力在钳内自平衡（活动钳爪 ↔ 推杆 ↔ 螺母 ↔ 丝杠 ↔ 推力轴承 ↔ 钳体）。只有被夹物体的重量与惯性力传到钳基座，再进入前端框架。

## B. 分系统结构

### B.1 中央承载躯干

- **主体骨架**：纵向承载式箱型框架，长 1020 mm（前板 x = +500，尾根 x = −520），髋部处半宽 240 mm。
  - 中央纵向承载梁：7075-T6 铝合金 CNC 箱梁，截面约 340 × 160 mm，壁厚 6 mm，内部纵向加强筋。
  - 左右侧承载梁：7075 铝合金，每侧 4 个髋座安装面，髋点坐标 x = +260 / +90 / −80 / −250 mm，|z| = 210 / 230 / 230 / 210 mm，高度 420 mm（髋线 `BODY.ride`）。
  - 前端安装框架：合金钢焊接框（钳基座承受夹持物惯性载荷），左右钳基座位于 (460, 440, ±170) mm。
  - 后端承载框架：合金钢 + 7075 组合件，尾根连接座的安装面；J1 位于 (−500, 490) mm，在后端框架内 20 mm。
  - 横向加强梁：在 4 对髋座之间各一道，共 5 道，与侧梁用铰制孔螺栓连接，防止扭转变形。
  - 底部设备托架：6061 铝合金托盘，四点弹性吊装在纵向梁下，安装动力舱与散热舱。
- **五个功能舱**（自下而上、由前到后）：

| 舱 | 位置（质心 mm） | 内容 |
|---|---|---|
| 动力舱 | 底层中央 (40, 350, 0) | 电池模组 + BMS，68 kg |
| 散热舱 | 底层后部 (−120, 370, 0) | 液冷泵、冷板集管、散热器、两台风扇 |
| 驱动舱 | 中层后部 (−300, 430, 0) | 分区伺服驱动器、电源分配器 (−220, 370, 0) |
| 控制舱 | 中层前部 (220, 460, 0) | 中央计算机、运动控制器、通信模块 |
| 传感舱 | 前端 (500, 500, 0) | 双目、深度相机、激光雷达、IMU（IMU 靠近整机质心布置在控制舱底板） |

  各舱有独立的安装框和舱壁，高压与低压线束分走左右两侧线槽，运动部件（髋驱动器）全部位于舱外的侧梁上。
- **主体装甲**（三层）：外部白色弧形复合装甲板（玻纤/碳纤维模压，分块，带接缝、螺栓孔、检修盖板与散热开口）→ 弹性缓冲隔离层（硅橡胶减振垫 + 金属限位套）→ 承载骨架。装甲板不承担主载荷，每块单独拆装。

### B.2 八足机械腿

- **几何**（`LEG`）：髋偏航臂（coxa）110 mm，大腿 400 mm，小腿 700 mm；站立时膝关节高 685–700 mm，形成三视图中高拱的蜘蛛腿轮廓。足端中性点在地面上距髋点 478 mm，按俯视图向外呈扇形展开：第 1–4 对中性偏航角为 +38° / +12° / −14° / −40°（正值向前）。
- **单腿组成**：
  - A 髋部安装座：钢制法兰与侧梁连接（8 × M8 12.9 级，螺栓分布圆 Ø120 mm）。座内两台驱动器：髋偏航（竖直轴）+ 髋俯仰（水平轴），两轴正交。偏航输出盘直接驱动俯仰驱动器壳体。
  - B 第一段腿臂（大腿）：7075 中空箱型连杆，外形约 80 × 75 mm、壁厚 4 mm，内设两道横筋，内腔走线；外覆白色流线装甲，装甲下露出黑色骨架。
  - C 第二段腿臂（小腿）：6061/7075 铝合金，膝端与踝端为钢制承力接头；膝关节单轴，黑色圆形关节壳体 + 橙红色防护环。
  - D 末端足部：被动踝（俯仰 −40°…+25° 扭簧回中，侧摆 ±10° 弹性体），钢制针状足骨架 + 橙色护套、耐磨橡胶足垫（Ø40 mm），足底压力传感器、接触开关、弹性体缓冲。踝角由 kin.js `ankle` 给出（保持足垫贴地），行走时实际范围 −36°…0°。
- **驱动**：永磁同步伺服电机 + 谐波（或行星 + 谐波两级）减速器 + 绝对式编码器 + 电流反馈。髋俯仰与膝关节带失电制动器，断电后整机不会塌落。髋俯仰另配扭矩传感器，用于足力分配。
- **扭矩**（行走 + 抬腿 + 静止落足全扫描）：髋俯仰峰值 444 N·m，膝 129 N·m，髋偏航 175 N·m（0.3 g 水平牵引）。膝扭矩远小于髋俯仰扭矩，是因为高拱的膝关节靠近足端正上方：膝到足的水平力臂最大只有 194 mm，而髋俯仰轴到足的水平力臂可达 476 mm。小腿加长到 700 mm 后，膝到足的力臂变大，膝扭矩由 108 升到 129 N·m；足距收窄后，髋俯仰扭矩由 493 降到 444 N·m。

### B.3 双机械钳

- **几何**（`CLAW`）：肩部（基座）在 (460, 440, ±170) mm；上臂 250 mm，前臂 250 mm，钳掌 180 mm，钳指 225 mm。按三视图，钳体外张、低位前伸：基座偏航 44°（外张），前臂下压 −34°，钳体（螯）外壳约为腕部截面的 3 倍高、2 倍宽（造型见 `claws.js`）。
- **关节**：基座 2-DOF（偏航 + 俯仰，前端框架法兰）、肘（斜轴）、腕（近竖直轴）、夹爪开合，共 5 个主动自由度/钳。
- **钳体**：固定钳体为中空钢/铝骨架，外覆白色弧形装甲；活动钳爪为 42CrMo 钢骨架，末端装黑色可更换耐磨夹持垫（燕尾槽 + 2 颗 M5 沉头螺钉）。闭合时两钳指形成弧形夹持空间。
- **夹爪驱动方案选择：电动梯形丝杠（规范 §4.3 方案一）**

  传动链：伺服电机 → 单级行星减速器 10:1 → Tr20×4 梯形丝杠（单线，导程 4 mm）→ 青铜螺母（长 50 mm，12.5 圈啮合）→ 推杆（110 mm）→ 活动钳爪（单铰轴，曲柄销半径 80 mm）。

  选择理由（与对称齿轮方案对比）：

  | 比较项 | 梯形丝杠 + 推杆（选定） | 对称齿轮同步开合 |
  |---|---|---|
  | 失电保持 | 导程角 4.05° < 摩擦角 5.91°，自锁，断电后夹持力保持 | 齿轮可反驱，需额外制动器 |
  | 力放大 | 闭合时推杆沿丝杠轴线，有效力臂 80 mm 为最大，夹紧时力最大 | 力臂恒定 |
  | 体积 | 丝杠沿钳掌纵向布置，装入 180 mm 钳掌内 | 齿轮组需要横向空间，钳体变厚 |
  | 夹持力测量 | 螺母上的测力环直接测轴向力 | 需关节扭矩传感器 |
  | 缺点 | 效率 40 %，开合较慢（全行程 2.19 s） | 速度快 |

  蝎螯是一根固定指加一根活动指，单侧活动更符合原造型，不需要两指同步，所以选丝杠方案。

  kin.js 计算结果（`CLAW_DRIVE`、`clawDrive(gap)`）：

  | 参数 | 数值 |
  |---|---|
  | 电机 | 1.0 kW 永磁同步伺服，额定 3.18 N·m，峰值 9.55 N·m，3000 rpm |
  | 丝杠导程角 / 摩擦角（μ = 0.10，牙型半角 15°） | 4.05° / 5.91°，自锁 |
  | 丝杠效率 / 行星效率 | 0.403 / 0.95 |
  | 螺母轴向力（电机额定扭矩） | 19.1 kN |
  | 夹持 6.2 kN 所需（钳垫中心距铰轴 140 mm） | 铰轴扭矩 868 N·m → 螺母 10.85 kN → 电机 1.80 N·m |
  | 闭合位额定铰轴扭矩 | 1530 N·m（1.76 × 需求） |
  | 螺母行程（0 → 34° 全开） | 43.9 mm，丝杠 10.97 圈，电机 109.7 圈 |
  | 全开时间（3000 rpm） | 2.19 s |

### B.5 尾端执行机构（Stinger Module）

- **组成**：尾端快换安装法兰（4 × M6 + 定位销 + 快换电连接器）、J8 小型俯仰关节（谐波 80:1 + 扭矩限制滑差离合器，−75°/+60°）、高强度连接骨架（钛合金 TC4）、传感器安装舱（接触/力传感器、温度探头、可选小型相机）、可拆卸黑色尖端外壳（卡口 + 1 颗止动螺钉）。
- **定位**：具有冲击能力的末端执行器，同时作为环境探测探针、接触检测器和专用工具的安装位。尾刺通过 J8 和末端安装节实体连接到第六节连杆，不是装饰尖头。
- **载荷与保护**（规范 §5.5 要求明确标注）。尾刺有两个不同的载荷值，分别用于不同工况：

  | 载荷 | 数值 | 含义 | 来源 |
  |---|---|---|---|
  | 峰值冲击力 | **1200 N**（`STINGER.impact` = `SPEC.strike`，与原理图一致） | 冲刺过程中尖端撞击目标时的瞬时峰值，从接触到峰值约 31 ms | `impactAt()` |
  | 静态保持/按压力 | **100 N**（`STINGER.force`） | 冲刺到位后尖端持续压住目标的力 | 尾部关节额定扭矩 |

  - **静态 100 N 的计算**：冲刺到位时尖端沿尾刺轴线（−44°）受力。J1 力臂 671 mm、J2 583 mm、J3 440 mm。按 (额定扭矩 − 自重弯矩) / 力臂计算，各关节余量为 J1 128 N、J2 106 N、J3 113 N。J2 最小，取整为 100 N，限制关节为 J2。
  - **峰值冲击 1200 N 的计算**（`impactAt(s, stop)`，参数 `IMPACT`）：
    1. 接触时刻：冲刺行程 s = 0.90（`IMPACT.contactS`），即冲刺开始后 0.590 s，前刺尚未结束，尖端仍在运动。
    2. 尖端轴向速度：v = (d尖端轴向位移/ds) × ds/dt = 1.01 m/s，ds/dt 取自 `strikeCurve`。
    3. 尖端等效质量：m = Σ mᵢ·|dpᵢ/ds|² / (d尖端/ds)² = 23.7 kg，对尾部 15 个集中质量求和，与 `cogAt` 使用同一组质量点。
    4. 尖端柔性缓冲：弹簧尖套 + 聚氨酯缓冲叠层，压缩行程 20 mm（`IMPACT.stop`），按线性弹簧计算。峰值力 F = m·v² / 行程 = **1205 N ≈ 1200 N**。
    5. 从接触到峰值约 31.2 ms，冲量 23.9 N·s，尖端减速度 50.8 m/s²。
    6. 假设：目标为刚性，减速全部由尖端柔性缓冲吸收，对力的估计偏保守；接触期间各尾关节驱动器处于扭矩限幅状态，整条尾链沿冲刺路径作为一个整体减速；反弹由缓冲材料阻尼吸收。
    7. 灵敏度：缓冲行程 25 mm 时峰值为 964 N，15 mm 时为 1607 N；接触点提前到 s = 0.88 时峰值为 1541 N，推迟到 s = 0.92 时为 892 N。因此冲击强度由控制器选择接触点、由缓冲件选择行程，1200 N 是额定设计点。
  - **冲击峰值时的关节载荷**：峰值时刻尾链瞬时静止，重力、减速惯性力与目标反力共同作用。各关节载荷为 J1 86 / J2 2 / J3 73 / J4 101 / J5 76 / J6 24 / J7 13 / J8 3 N·m。C 节的尾关节额定扭矩取 1.5 × 静峰值与冲击峰值中的较大者（J4、J5 由冲击载荷决定），所以全部不超过额定值（`STINGER.impactOk` = true）。冲击力之所以能达到静态保持力的 12 倍，是因为大部分冲击力由尾链自身的减速惯性平衡，没有经过尾根的长力臂。
  - J8 滑差离合器 10 N·m 打滑，作为最后一级机械保护。尖端力传感器读数超过 1200 N，或冲刺到位后按压力超过 100 N 时，控制器停止并回退。
  - 机械限位：J8 −75°/+60° 硬限位块（蓄力后摆时实际使用到 −63°）；冲刺轨迹由软件限制在躯干装甲上方，冲刺到位时尖端位于 (245, 703) mm，比头部装甲顶面（约 590 mm）高约 110 mm。
  - 冲刺时尖端前方 0.5 m 为危险区，有人员时（激光雷达检测）禁止冲刺。

### B.6 动力系统

- **架构**：集中式电源 + 分布式驱动。
- **主电源**（动力舱，68 kg，质心 (40, 350, 0) mm）：模块化高压锂电池，估算 400 V 标称、约 10 kWh（按 68 kg 中电芯约 75 %、电芯 200 Wh/kg 估算）。含 BMS、主接触器、预充电电路、高压保险、直流母线、隔离式 DC/DC 辅助电源（48 V 与 24 V）。电源分配器 6 kg 位于 (−220, 370, 0) mm。
- **分布式供电**：400 V 母线 → 驱动舱的四个分区驱动模块（左腿、右腿、前钳、尾部）。各模块再通过腿部、钳部和尾部线束送到关节附近的驱动器。线束有防磨护套、拉扯固定夹、编织屏蔽层，在关节处留足活动余量，每个模块之间都用可检修的快插连接器。
- **功率估算**：43 个主动关节，行走时 8 个髋俯仰轴的平均功率最大。行走 0.35 m/s 时整机电功率估算约 1.2 kW，10 kWh 可工作约 8 h，与 `SPEC.endurance` = 8 h 一致。这是估算，需在样机上实测。

### B.7 运动控制与传感系统

- **前端传感头**（传感舱，7 kg，(500, 500, 0) mm）：双目视觉相机、深度相机、激光雷达、红外测温（可选）、环境照明；外部为深色玻璃防护窗。
- **关节传感**：每个主动关节配绝对式编码器、电机温度、相电流检测；髋俯仰、尾 J1/J2 另配扭矩传感器；足底配压力传感器与接触开关。
- **姿态控制**：九轴 IMU 安装在控制舱底板上，靠近整机质心。控制器实时读取横滚、俯仰、偏航、角速度与加速度。
- **控制层次**：
  1. 步态规划：交替四足步态，占空比 0.58，步幅 0.30 m，抬脚高度 0.10 m。
  2. 足力分配：最小二乘（kin.js `footForces`）。
  3. 关节伺服：位置环、速度环、电流环。
  4. 安全监控：支撑裕度 < 100 mm 时降速，冲刺与夹持过载停机。

## E. 运动学设计

### E.1 腿部

- **自由度**：每腿 3 个主动（髋偏航、髋俯仰、膝）+ 1 个被动（踝）。逆运动学为解析解（`legIK`），先求偏航角，再在腿平面内用余弦定理求解。膝关节始终在上（knee-up 构型），与原蝎形外观一致。
- **步态**（`footAt`）：交替四足步态。L1 R2 L3 R4 为一组，R1 L2 R3 L4 为另一组，两组相位差 0.5；每组内部由后向前有 0.04 周期的波浪偏移。
  - 占空比 0.58，步幅 0.30 m（每周期机身前进 0.30 m，频率随速度变化），抬脚高度 0.10 m。
  - 0.35 m/s 时步频 1.17 Hz，周期 0.86 s，单腿摆动 0.36 s；0.9 m/s 时步频 3.0 Hz。
  - 支撑期足端在机身坐标系内向后匀速移动，速度等于机身速度，因此不打滑。
  - 机身随换腿有 ±12 mm 的上下起伏（`bobAt`），静止时起伏消失。
- **实际使用的关节角**（全周期扫描）：

| 关节 | 实际范围 | 机械限位 | 余量 |
|---|---|---|---|
| 髋偏航（相对本对中性角 +38/+12/−14/−40°） | −18° ~ +18° | ±35° | 17° |
| 髋俯仰（大腿相对水平，上为正） | 40° ~ 96° | 0° ~ 120° | 24° 以上 |
| 膝（弯折角） | 99° ~ 152° | 60° ~ 170° | 18° 以上 |
| 被动踝 | −36° ~ 0° | −40° ~ 25° | 4° |

  大腿高抬（最大 96°，即越过竖直）、小腿陡直向下，这是长小腿高拱膝构型的特点。

- **抬腿**（`legsAt(PHI, lift)`）：L1 足端可抬高 240 mm，并向外前方伸出 60 mm，到 (679, 240, 634) mm，用于越障与展示。其余 7 足分担 4120 N，单足 342–809 N；支撑裕度不小于 246 mm。
- **静止**（`settle`）：摆动中的足垂直落地，8 足着地，支撑裕度不小于 509 mm。

### E.2 尾部弯曲方式

- J1 双自由度：先绕竖直轴偏航（±30°，演示中 ±25°），再俯仰；其余关节都是平行的俯仰轴，组合成连续弧线。`tailAt` 先在尾平面内求出各节点，再整体绕尾根竖直轴旋转。
- 一个参数 s 控制冲刺：每个关节角 = 静止角 + strike × s + stow × w，所以各关节同时到位，弧线始终连续。冲刺曲线（`strikeCurve`，1.6 s）：0–0.48 s 蓄力后摆到 s = −0.28；0.48–0.67 s 快速前刺到 s = 1；保持到 0.99 s；之后平滑收回。
- 实际使用的相对角：J1 99°–130°（绝对俯仰）、J2 −24°~−19°、J3 −25°~−20°、J4 −27°~−24°、J5 −30°~−29°、J6 −35°~−30°、J7 −39°~−30°、J8 −63°~+14°，全部在 C 节限位以内。
- 各关节静弯矩（N·m，`tailAt().torque`，J1 俯仰 → J8）：

| 姿态 | J1 | J2 | J3 | J4 | J5 | J6 | J7 | J8 |
|---|---|---|---|---|---|---|---|---|
| 静止 | 1 | 45 | 62 | 55 | 38 | 18 | 6 | 0 |
| 冲刺到位 | 74 | 98 | 90 | 66 | 39 | 18 | 7 | 3 |
| 蓄力后摆 | 23 | 29 | 51 | 50 | 36 | 18 | 5 | 1 |
| 低姿收尾 | 15 | 55 | 65 | 55 | 37 | 17 | 4 | 0 |
| 全行程峰值（选型用） | 91 | 106 | 92 | 66 | 40 | 19 | 7 | 3 |
| 1200 N 冲击峰值时 | 86 | 2 | 73 | 101 | 76 | 24 | 13 | 3 |

  静止姿态 J1 只有 1 N·m：高举的尾弧质心几乎正好在 J1 上方，这是蝎尾高举造型在力学上的好处。冲刺时尾巴前倾，J1 弯矩上升到 74 N·m。

### E.3 机械钳开合方式

- 钳臂姿态由参数 reach（0 收拢 → 1 伸展）控制。基座偏航从 44°（外张）变到 32°，基座俯仰从 14° 变到 8°，前臂俯仰从 −34° 变到 −22°。钳尖从 (1265, 326, 234) mm 移到 (1333, 346, 256) mm，全开伸展时整机长度的最前点为 x = 1343 mm。
- 开合由参数 open（0 → 1）控制，对应钳爪开角 0° → 34°。螺母、丝杠圈数与推杆角由 `clawDrive` 换算（见 B.3）。夹持力 = 6.2 kN × (1 − open) × (0.15 + 0.85 × squeeze)（`gripForce`）。

### E.4 系统协调

- **重心管理**：冲刺使重心前移 18 mm（−12 → 6 mm），双钳伸展只移动 2 mm。即使冲刺、双钳全开全伸展、尾部偏转 25° 与行走同时发生，支撑裕度最小仍有 265 mm。控制器仍按 `supportAt` 实时计算裕度。
- **冲刺**：只在静止（8 足着地，裕度 509 mm）或慢走时触发；冲刺前把前两对腿的足端力上调，以抵消前移的重心。
- **抬腿**：先把重心向对侧后方移动（7 足支撑多边形的中心），再抬起 L1。
- **双钳与前腿**：钳臂到 L1 膝关节的最小距离为 234 mm，两者可以同时动作。

### H.2 重心

- 站立重心 (−12, 488, −1) mm；行走中重心高度在 478–504 mm 之间，左右偏差不超过 5 mm。
- 静稳定裕度：0.35 m/s 行走 ≥ 271 mm（4–7 足着地，最不利时刻为 PHI = 0.58，4 足着地）；加上冲刺、钳伸展和尾偏转 ≥ 265 mm；L1 抬起 ≥ 246 mm；静止 ≥ 509 mm。
- 风险：重心比髋线高 68 mm，原因是尾部（58 kg，质心高 832 mm）和高拱的长腿（腿部质心 463 mm）。足距收窄后，支撑多边形比上一版小，裕度从 295 mm 降到 271 mm，但仍远大于控制器的 100 mm 降速阈值。若要进一步降低重心，可把电池再下移 30 mm，或把膝驱动器移到大腿根部、用连杆传动到膝关节。
- 高速步态（0.9 m/s、3 Hz）下需要动态平衡控制，静态裕度仅作参考。

### H.3 热管理

- 发热源：43 台伺服电机（行走时主要是 8 台髋俯仰），驱动器，电池。
- 方案：驱动舱冷板液冷 + 电池冷板 + 散热舱散热器与风扇，风道从底部进风，侧面格栅排风（开口布置在侧甲下沿和底部，不破坏外观）。腿部电机靠壳体传导到连杆和装甲内侧散热。
- 监控：每台电机、驱动器、电池模组都有温度传感器；超过 80 °C 降额，超过 100 °C 停机。
- 风险：髋俯仰电机持续承受约 50–70 % 的额定扭矩，是热风险最高的位置，需在样机上做 8 h 连续行走温升测试。

### H.4 线缆布置

- 腿部：线束穿过髋偏航与俯仰驱动器的中空轴，沿大腿内腔走到膝关节，在关节外侧留 1.5 倍余量，护套防磨。
- 尾部：9 个关节连续弯曲。线束穿过中空轴，在关节外侧用柔性拖链跨接；最小弯曲半径 ≥ 10 × 线径，并加防夹罩。J1 偏航 ±30° 的扭转由一段螺旋线缆吸收。
- 钳部：夹爪电机线沿钳臂内腔走线，肘、腕关节处留余量。
- 高压与低压线束分侧走线，带屏蔽层，以减少电磁干扰。

### H.6 维修空间

- 装甲板单独拆装，拆下后可接触所有关节与线束连接器。
- 电池从底部检修盖板抽出，散热舱滤网从侧面拆出；整腿、整钳、尾节、尾刺都可以作为模块整体更换。
- 减速器润滑：谐波减速器使用长寿命润滑脂，约 2000 h 补脂一次；丝杠螺母每 500 h 补脂，通过钳掌检修盖操作。轴承在关节模块返厂时更换。
- 风险：中部两对腿的髋座位于功能舱侧面，拆卸时需要先拆侧甲和该侧的线槽盖板。

### H.7 遗留问题

1. 尾刺 1200 N 是峰值冲击力，依赖 20 mm 尖端缓冲行程和 s = 0.90 的接触点。目标偏软时峰值会降低，缓冲件老化变硬时峰值会升高（15 mm 行程时为 1607 N，此时 J3、J4、J5 都会超出额定扭矩）。需要用尖端力传感器做闭环监控，并通过样机冲击试验标定。持续按压只允许 100 N。
2. 动力电量、续航与热负荷都是估算，需要做样机测试。
3. 同侧膝关节间距 116 mm，余量偏小，建议在详细设计中复核装甲外形。
4. 除尾刺冲击（`impactAt`）外，本文的关节扭矩都是静态计算。其他动态载荷（落地冲击、高速步态）由 1.5 倍系数、电流限幅和扭矩反馈覆盖，仍需在样机上实测。
5. 整机高度 1260 mm，距 1280 mm 上限还有 20 mm 余量。
